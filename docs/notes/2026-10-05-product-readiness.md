# 小婉安装与任务闭环

本轮保持 Harness alpha.1、Cordis/Jev、FunASR、Qwen3 0.6B Serena、原模型路由和同一人物素材。新增 Windows 只读诊断、按阶段调用现有安装脚本的入口和仅进程内使用凭据的配置向导；不安装系统软件或驱动，不自动下载模型、批准预算、启动服务或重试收费请求。

模型工具默认输出计划，复制和下载需要显式执行。Qwen 和 Silero 使用固定官方版本；FunASR 六个文件的完整固定官方快照尚未证明，因此保持精确哈希复制，不静默改用当前最新版。传输保留部分文件，验证完整大小和 SHA-256 后才接受目标；Range 不支持或哈希错误时等待显式处理。

配置检查先于新 Jev 决策，拒绝未授权预算、未核实 Flash 报价和不足首请求最低保留额的余量。原每请求预算、文件原生审批、上下文限制、音频取消和 bounded recovery 保留。Provider 错误只投影固定文案与稳定代码，不将响应正文、凭据、机器路径或失败 replay 放入会话。

任务面板只投影当前会话的真实状态和工具成果；成果下载继承 Harness 的浏览器 Cookie 与 Host/Origin 检查，要求已审批写入记录且当前文件大小和哈希一致。下载使用附件和 nosniff，不在已登录页面执行生成的 HTML 或脚本。只读状态不列出任意工作目录或任务私聊。

安装升级只替换字节哈希等于上次安装记录的 UI 文件。旧 marker 没有逐文件记录时，只接受 436bf4f 的明确 LF/CRLF checkout 哈希。已有本地改动、未知同名文件或链接会阻止覆盖；未知额外文件不删除。多文件安装不承诺系统崩溃时的事务回滚。

验收使用合成配置、本地 HTTP 传输、离线 ASGI 和 UI 交互 fixture。原工作树和运行服务保持；没有模型推理或新的费用调用。全新 GPU 机器的系统安装与真实语音仍需另行验收，预设动作不代表实时精确口型。
