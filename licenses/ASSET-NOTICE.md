# Local assets

The portrait is the user-approved original fictional adult image. It is loaded locally; no publication license is inferred. The silent preview was generated locally with Ditto dependencies whose stock pretrained face models have noncommercial/research restrictions. Both binaries are intentionally ignored by Git. The public repository includes only their provenance manifest; no source-reference video/audio, model weights, private user records or credentials are included.

The preview implementation is newly authored. Its bounded file-save behavior is adapted from the previous local prototype; no third-party source code is copied into these server files. DeepSeek Harness remains a separately cloned MIT upstream, excluded from this repository. No code from dsh-voice-ai-girlfriend has yet been incorporated.
