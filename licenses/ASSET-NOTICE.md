# Character assets in this delivery

The user explicitly requested publication of the existing AI companion with the same character, functions and necessary non-sensitive character assets. `public/assets/portrait.png` is the existing approved fictional adult portrait. `public/assets/investor-preview-v1/` contains the exact poster and muted video cuts referenced by the current author VoiceBridge UI. They were copied without re-encoding or changing the character. Their byte counts and SHA-256 hashes are recorded in the adjacent manifests.

The current character has long black hair, a cream camisole, a flower pendant and a warm indoor background. The poster is a frame from the approved action media and is not byte-identical to the source portrait. The UI uses this poster and the cached action clips; the original portrait is preserved for the existing static route and explicitly approved photo-conditioned workflows.

These clips are preset playback. They do not produce live facial animation or synchronize mouth movements to newly generated speech. The current player uses `quiet-v2.mp4` as the quiet loop and periodically plays `listening.mp4` or `speaking.mp4` following real lifecycle facts. All six video files contain H.264 video at 720 × 960 with no audio stream. The other state files remain included because the current component references and preloads them.

Only the user's publication authorization for this delivery is recorded here; this notice does not assert an additional third-party media license or change the licenses of model dependencies. No unrelated upstream default character media is included. The old Ditto idle preview, previous DUIX lip-sync research outputs, test audio, private recordings, personal data, logs and model weights are excluded.
