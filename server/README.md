# Local runtime integration surface

`createApp(options)` returns a Node HTTP request handler with `.jobs`, `.status()`, `.dataRoot`, `.close()`. `createServer(options)` returns an unbound `http.Server` with `.app`. Tests can bind port 0 on 127.0.0.1.

Options: `dataRoot`, `publicRoot`, `adapters: {chat, jev, harness}`, `logger(eventObject)`, `beforeCommit` (test hook), `allowExternalCalls` (false by default). No environment provider credentials are imported. Chat adapter: `{configured:true, complete({text,requestId,turnId,signal}):Promise<{text}>}`. Jev/Harness are held only as explicit status seams; they are **not executed** yet. No production mock adapters.

`GET /api/status` is authoritative. Chat POST requires a UUID turnId and text. Duplicate turn IDs are rejected. `/api/turns/:id/cancel` aborts only that chat. `/api/audio/stop` does not cancel jobs. File jobs use durable local JSON journals, UUID id/turnId, monotonically increasing revision, and idempotent repeated creates. Task cancellation accepts optional expectedRevision; stale revisions return409. Frontend ignores wrong ID/turnId or older revisions.

Developer configuration: `GET /api/admin/bootstrap` establishes 30-minute HttpOnly SameSite=Strict cookie `companion_admin` scoped `/api/admin` and returns csrfToken plus providers. POST `/api/admin/config` requires exact loopback Origin, cookie, and X-CSRF-Token. Providers enum `deepseek|jev`; input fields `provider,apiKey?,model?,baseUrl?,clear?`. Missing key preserves previous key; clear=true deletes only that provider. DeepSeek model required. Official URLs are https://api.deepseek.com and https://api.typesafe.ai; no other endpoint is currently accepted. Response `{providers:{deepseek:{configured,baseUrl,model,connected:false},jev:{configured,baseUrl,model,connected:false}},saved:true,connectionTested:false,requestId}` contains no secret. GET config requires cookie/CSRF too. Saved keys are not loaded into any runtime adapter yet. POST admin/test returns503 without outbound calls.

Private local file: data/private-config/providers.json (ignored). Application requests mode0700/0600 on platforms supporting Unix modes; Windows uses the existing project directory access inheritance. No system ACL changes or encryption claim. Loopback+origin+CSRF prevents browser cross-site writes; this is not multi-user authentication or protection against hostile local processes. Production needs admin authentication and a server-side vault. Never log/read back keys or record filled configuration forms.
